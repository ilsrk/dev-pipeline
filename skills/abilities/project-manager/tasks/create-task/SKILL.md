# Task initial

Creating a task in the user's task management system.

## Conventions

- Each task must have a unique identifier and a title.
- Each task must have a detailed description.

## Steps

- Each task must have a detailed description.
- Check that the task does not already exist.
- Create a task.

## Hard constraints

- Do not write code.
- Do not analyze the codebase or technical documentation.
