# Tetings requirenments

## Steps

- Review the user requirements
  - Check that all requirements include acceptance criteria.
- Review the non-functional requirements
  - Check that all requirements are achievable and realistic.
- Review the constraints
  - Check that the constraints are justified.
- Review the assumptions
  - Check that the assumptions are justified.

## Constraints

- When referencing requirements or user stories, always include a short title alongside the identifier.
- Show only the findings.
